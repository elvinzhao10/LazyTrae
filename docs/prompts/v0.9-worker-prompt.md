Loop states:
- idle
- initializing
- planning
- active
- verifying
- reviewing
- blocked
- paused
- complete
- cancelled

Loop cycle:
1. Load memory.
2. Normalize goal.
3. Create completion promise.
4. Generate/load plan.
5. Select next task.
6. Implement one bounded unit.
7. Verify.
8. Retry or block on failure.
9. Review.
10. Update memory.
11. Continue or complete.
