# LazyTrae v0.12 — Worker Delegation Prompt
> Extracted from plan/v0.12-dogfood.md

LazyTrae v0.12 — Dogfood LazyTrae on itself.

Choose one small real task:
- improve one skill
- add missing verification detail
- fix parity-ledger gap
- add smoke test
- improve docs consistency

Use the LazyTrae workflow:
1. init-deep
2. ulw-plan
3. start-work
4. verifier
5. reviewer
6. librarian update
7. ulw-loop if verification fails
8. handoff

Required files:
- docs/lazytrae-dogfood-run.md
- docs/lazytrae-dogfood-plan.md
- docs/lazytrae-dogfood-review.md
- updated docs/lazytrae-parity-ledger.md
- updated docs/lazytrae-risk-register.md

Dogfood report:
- selected task
- why selected
- plan
- implementation summary
- files changed
- verification commands/results
- reviewer decision
- librarian update
- final pass/fail status

Do not hide failures.
