# LazyTrae v0.11 — Team Mode / Parallel Work Adaptation

> **Version 0 build.** Part of the v0.x series.

## Objective

Recreate OmO-style parallelism creatively.

## Native Version

- Use Trae SOLO subagents for read-heavy specialist work.
- Use custom agents for Planner, Reviewer, Explorer, Librarian.
- Use one main orchestrator context for synthesis.

## Optional Runtime Version

```
.lazytraework/team/
  team.json
  members/
  mailbox/
  tasklist.jsonl
  worktrees/
```

## Commands

```bash
lazytrae team create
lazytrae team spawn explorer
lazytrae team spawn reviewer
lazytrae team status
lazytrae team collect
```

## Rules

- Parallel read-heavy tasks are allowed.
- Parallel write-heavy tasks require separate worktrees.
- Reviewer, Librarian, Explorer are read-only by default.
- Main orchestrator must synthesize all results.

## Verification

- Spawn two read-only workers against fixture repo.
- Confirm separate logs.
- Confirm parent synthesis report.
- Confirm no write conflicts.

## Success Criteria

LazyTrae can parallelize exploration/review without corrupting implementation state.

## Rollback

Disable team config and remove `.lazytraework/team` runtime state.
