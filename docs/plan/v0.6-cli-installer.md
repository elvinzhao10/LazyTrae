# LazyTrae v0.6 — CLI Installer and Doctor

> **Version 0 build.** Part of the v0.x series.

## Objective

Package LazyTrae so users do not hand-copy files.

## Commands

```bash
lazytrae init
lazytrae doctor
lazytrae sync
lazytrae uninstall
lazytrae verify
lazytrae handoff
```

## init Behavior

- Detect repo root.
- Create `.trae` artifacts.
- Create `.lazytrae` runtime directories.
- Create `.workflow` compatibility directories.
- Generate or merge `AGENTS.md`.
- Install rules, skills, commands, agents, hooks, MCP config.
- Use managed blocks to avoid overwriting user content.

## doctor Checks

- Required files exist.
- Skills have SKILL.md.
- Commands exist.
- Agent prompts exist.
- Rules exist.
- State schemas validate.
- `.workflow` mirror is present.
- MCP config parses.
- Hook scripts are executable where applicable.
- Parity ledger covers all discovered historical source record methods.

## sync Behavior

- Update managed files.
- Preserve user edits outside managed blocks.
- Migrate schema versions.
- Refresh command/skill templates.

## uninstall Behavior

- Remove managed LazyTrae files/blocks.
- Preserve plans/evidence by default.
- Support `--purge-state` for full cleanup.

## Verification

- Run init twice; confirm idempotency.
- Run doctor; confirm pass.
- Modify a managed block and run sync; confirm repair.
- Run uninstall; confirm user content preserved.

## Success Criteria

A developer can install LazyTrae into any repo safely.

## Rollback

Use `lazytrae uninstall`.

## Verification Notes

### historical source record installer (verified from source repo)

- historical source record — thin alias to `npx oh-my-openagent workflow install --platform=codex`
- `npx historical source record install` — primary install path
- `npx historical source record doctor` — prints installation health report: plugin cache, hooks, MCP servers, agents, config state
- `npx historical source record uninstall` — removes plugin cache, bin links, agent roles, managed config sections
- Marketplace alternative: `codex plugin marketplace add` and `codex plugin add workflow@sisyphuslabs`
- Bootstrap runs in background after first approval: config blocks, agent roles, bin links, pinned `sg` binary
