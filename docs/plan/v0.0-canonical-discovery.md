# LazyTrae v0.0 — Canonical Discovery

> **Version 0 build.** Part of the v0.x series.

## Objective

Force the implementation agent to inspect the actual historical source record repo before inventing behavior.

## Deliverables

- historical source record
- `docs/lazytrae-host-adaptation-map.md`
- `docs/lazytrae-v0-discovery-report.md`
- historical source record

## Implementation Steps

1. Locate historical source record repo root.
2. Inspect README, package files, plugin manifests, command files, hooks, skills, agents, MCP config, tests, and docs.
3. Extract every command, skill, agent, hook, script, state file, and verification workflow.
4. Classify each feature:
   - core semantic behavior
   - host-specific implementation detail
   - portable
   - partially portable
   - not portable
5. Produce a canonical method map with exact source paths.

## Verification

- Every discovered historical source record method has a source file/path.
- Every unknown is explicitly marked.
- No runtime files changed.

## Success Criteria

The method map is good enough that a different agent could implement LazyTrae without guessing.

## Rollback

Delete only the v0.0 docs.
