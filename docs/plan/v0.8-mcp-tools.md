# LazyTrae v0.8 — MCP and Tool Integration

> **Version 0 build.** Part of the v0.x series.

## Objective

Expose LazyTrae state and verification tools through MCP.

## Deliverables

- `.trae/mcp.json`
- `packages/mcp/src/server.ts`
- `docs/lazytrae-mcp-and-tools.md`

## LazyTrae MCP Tools

| Tool | Purpose |
| --- | --- |
| `lazytrae.get_active_plan` | Retrieve the current active plan |
| `lazytrae.get_boulder_status` | Get boulder state summary |
| `lazytrae.get_next_task` | Get the next actionable task |
| `lazytrae.record_evidence` | Record verification evidence |
| `lazytrae.mark_task_done` | Mark a task as complete with evidence |
| `lazytrae.add_blocker` | Record a blocker |
| `lazytrae.request_review` | Trigger a review cycle |
| `lazytrae.generate_handoff` | Generate a handoff summary |
| `lazytrae.get_parity_status` | Get parity ledger status |

## Optional MCP Templates

| MCP Server | Purpose |
| --- | --- |
| filesystem | File access |
| git | Git operations |
| playwright/browser | Browser automation |
| docs/context lookup | Documentation search |
| ast-grep | Structural code search |
| LSP diagnostics | Language server diagnostics |

## Verification

- Validate `.trae/mcp.json`.
- Start LazyTrae MCP server locally.
- Call `get_boulder_status`.
- Call `record_evidence`.
- Confirm evidence file changes.

## Success Criteria

Trae agents can query and mutate LazyTrae state through stable tools instead of editing JSON manually.

## Rollback

Disable LazyTrae MCP entry; core files still work manually.
