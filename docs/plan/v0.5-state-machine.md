## Core Behavior

### Plan Parser
Read Markdown plans and extract checklist tasks.

### Boulder State
Track active plan, current task, completed tasks, evidence, blockers, session ids.

### Loop State
Track long-horizon goal, iteration, checkpoints, completion promise, verification status, reviewer status.

### Evidence
Record commands run, outputs summarized, exit status, changed files, manual checks, reviewer findings.

### Completion
Completion is invalid unless:
- all required tasks are done,
- evidence exists,
- verification passed or waiver documented,
- reviewer/Oracle passed or caveats are accepted,
- handoff/completion file exists.

## Verification

- Create a test plan with checkboxes.
- Parse it into boulder state.
- Mark one task complete only with evidence.
- Attempt to complete without evidence and confirm it fails.

## Success Criteria

LazyTrae can resume work across sessions and cannot honestly mark long-horizon work complete without evidence.

## Rollback

Remove `.lazytraework/state` and `.lazytraework/schemas`, preserving docs.

## Verification Notes

### LazyCodex state files (verified from source repo)

- `.omo/boulder.json` — durable Boulder state, survives across turns and sessions (source: `docs/start-work.md`, `docs/discipline-agents.md`)
- `.omo/ulw-loop/` — loop state directory containing:
  - `goals.json` — plan with goals, success criteria, statuses
  - `evidence.jsonl` — evidence ledger
  - `checkpoints.jsonl` — checkpoint records
  - `brief.md` — original task brief
  - `ledger.jsonl` — audit trail of all mutations
- Goal statuses: pending, in_progress, complete, failed, blocked, review_blocked, needs_user_decision
- Steering mutations: add_subgoal, reorder_pending, revise_pending_wording, split_subgoal, mark_blocked_superseded, revise_criterion, annotate_ledger
- Five evidence gates: plan reread, automated verification, manual-QA, adversarial QA, cleanup

### Trae memory (verified from docs.trae.cn/ide_memories)

- Trae supports project-level memory
- Can be used for persistent context across sessions
- Complements the `.lazytraework/state/` file-based approach
