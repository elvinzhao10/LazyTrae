## SKILL.md Required Fields

Each SKILL.md must include:
- name
- description / trigger conditions
- canonical historical source record source reference
- purpose
- required context to inspect
- procedure
- allowed edits
- forbidden behavior
- verification gates
- failure handling
- output format
- handoff target

## Verification

- Every skill references the canonical method map.
- Every command has usage, inputs, outputs, and success criteria.
- No skill assumes unavailable tools.
- Command index and parity ledger updated.

## Success Criteria

A user can manually drive LazyTrae in Trae using skills/commands only.

## Rollback

Delete generated `.trae/skills` and `.trae/commands` directories.
