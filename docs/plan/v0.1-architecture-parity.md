Design the Trae-native architecture using v0.0 as the source of truth.

## Architecture Verification Notes

### Trae-native surface (verified from docs.trae.cn)

| Trae capability | historical source record equivalent | Confirmed |
| --- | --- | --- |
| Project Rules (`.trae/rules/`) | rules component | Yes |
| Skills (`SKILL.md`) | skills system | Yes |
| Slash Commands | `$init-deep`, `$ulw-plan`, `$start-work`, `$ulw-loop` | Yes |
| Custom Agents (prompts + MCP + tools) | agent roles (explorer, librarian, plan, etc.) | Yes |
| Subagents (callable by built-in Agent) | parallel explore subagents | Yes |
| Hooks (`hooks.json`, 6 event types) | Codex hooks (SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, PostCompact) | Yes — Trae has all except PostCompact |
| MCP (`.trae/mcp.json`) | MCP servers (grep_app, context7, codegraph, git_bash, lsp) | Yes |
| SOLO Mode (TRAE Work) | Team Mode parallelism | Yes |
| Memory | AGENTS.md project memory | Yes |

### Gap: PostCompact hook

Trae does not have a PostCompact hook event. historical source record uses PostCompact for cache resets and rule re-injection. LazyTrae must handle this via SessionStart detection of compaction or UserPromptSubmit context-pressure markers.
