## Objective

## Native Trae Strategy

| Category | Trae Mode | Agent |
| --- | --- | --- |
| quick | Auto mode / normal context | atlas |
| deep | Max mode for larger context and more tool use | hephaestus |
| ultrabrain | Max mode and strongest reasoning model available | oracle |
| visual-engineering | Max mode, visual/frontend-capable model | sisyphus |
| writing | Auto/default unless docs architecture is complex | librarian |
| review | Strongest available reasoning model, read-only stance | oracle |

## Optional Backend

Integrate Bytedance's open-source trae-agent CLI for explicit provider/model routing, trajectory recording, working-directory execution, file editing, bash, sequential thinking, MCP services, Docker mode, and trae-cli run.

Example:

```bash
lazytrae run --agent oracle --category ultrabrain "Review the current diff"
lazytrae run --agent explorer --category quick "Map the auth flow"
lazytrae run --loop active --trajectory .lazytrae/logs/active-loop.json
```

## Verification Notes

### LazyCodex model routing (verified from source repo)

- Role-based model profiles: default, plan mode, worker, verifier
- Baseline model: `gpt-5.5` with `high` reasoning (default), `xhigh` for plan mode
- Planning and exploration: strong reasoning model, large context
- Implementation turns: fast, capable coding model
- Verification: oracle model chosen for judgment
- Specialist skills: can target specific model profiles
- Source: `docs/model-routing.md`, `plugins/omo/model-catalog.json`

### Trae modes (verified from docs.trae.cn)

- **Auto mode**: standard context and tool usage
- **Max mode**: larger context window, more tool-heavy runs
- Custom model support available
- Source: https://docs.trae.cn/ide_auto-mode, https://docs.trae.cn/enterprise_max-mode
