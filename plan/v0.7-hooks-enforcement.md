# LazyTrae v0.7 — Hooks and Enforcement

> **Version 0 build.** Part of the v0.x series.

## Objective

Approximate LazyCodex's lifecycle enforcement using Trae hooks.

## Deliverables

- `.trae/hooks/session-start.sh`
- `.trae/hooks/user-prompt-submit.sh`
- `.trae/hooks/pre-tool-use.sh`
- `.trae/hooks/post-tool-use.sh`
- `.trae/hooks/stop.sh`
- `packages/cli/src/commands/hook.ts`

## Hook Dispatcher

```bash
lazytrae hook session-start
lazytrae hook user-prompt-submit
lazytrae hook pre-tool-use
lazytrae hook post-tool-use
lazytrae hook stop
```

## Hook Responsibilities

### session-start
Inject active plan, active loop, blockers, and next action.

### user-prompt-submit
Detect ulw, ultrawork, /start-work, /ulw-loop, /handoff, /stop-continuation.

### pre-tool-use
Enforce read-before-write where event metadata allows. Warn on destructive commands.

### post-tool-use
Record changed files. Run comment-checker if code was edited. Detect verification command outputs.

### stop
If active boulder/loop is incomplete, emit continuation prompt and prevent false completion where Trae allows.

## Verification

- Simulate hook events with JSON fixtures.
- Confirm active boulder status is injected.
- Confirm incomplete loop produces continuation reminder.
- Confirm comment-checker flags obvious AI-slop comments.

## Success Criteria

LazyTrae nudges Trae back to unfinished work instead of relying on conversation memory.

## Rollback

Disable hook config or remove `.trae/hooks`.

## Verification Notes

### LazyCodex hooks (verified from source repo)

Six hook events in LazyCodex/Codex:
1. **SessionStart** — rules loading, telemetry, auto-update, bootstrap, codegraph
2. **UserPromptSubmit** — rules re-injection, ultrawork trigger detection, ulw-loop steering
3. **PreToolUse** — git bash MCP guidance, ulw-loop goal budget protection
4. **PostToolUse** — comment checker, LSP diagnostics, codegraph init, apply_patch rule matching
5. **Stop/SubagentStop** — start-work continuation, executor evidence verification
6. **PostCompact** — git bash notification, rules and LSP cache resets

### Trae hooks (verified from docs.trae.cn/ide_automate-actions-with-hooks)

Six hook events in Trae:
1. **SessionStart** — after session created, before first conversation
2. **UserPromptSubmit** — after user sends query, before agent processes
3. **PreToolUse** — after agent initiates tool call, before execution
4. **PostToolUse** — after tool execution completes
5. **Stop** — when agent finishes output, about to end query
6. **Notification** — async, non-blocking (tool call waiting for confirmation, or task complete)

### Gap Analysis

| LazyCodex event | Trae event | Notes |
| --- | --- | --- |
| SessionStart | SessionStart | Direct mapping |
| UserPromptSubmit | UserPromptSubmit | Direct mapping |
| PreToolUse | PreToolUse | Direct mapping |
| PostToolUse | PostToolUse | Direct mapping |
| Stop/SubagentStop | Stop | Trae has single Stop event |
| PostCompact | (none) | **GAP** — must handle via SessionStart detection or UserPromptSubmit context-pressure markers |
| (none) | Notification | Trae-only — useful for async notifications |

Trae hooks config: `hooks.json` file, both global and project scope, shell command execution, sandbox or local auto-run modes.
