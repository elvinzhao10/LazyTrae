# ulw-loop

## Usage

`/lazy-ulw-loop [task brief]`

Triggers: `ulw-loop`, `ulw`, `ultrawork`, `durable execution`, `evidence-led work`, `run long-horizon task`

## Inputs

- Task brief: what the user wants to accomplish.
- Optional: `--heavy` to force HEAVY tier. Default: auto-classify.

## Outputs

- Ultrawork notepad with plan, todos, findings, learnings at `.lazytrae/notepad.md`.
- Loop state at `.lazytrae/state/active-loop.json`.
- Evidence files at `.lazytrae/evidence/`.
- Final report with outcome and success criteria checklist.

## Success Criteria

- Tier classified before execution.
- All success criteria have concrete evidence captured from real surfaces.
- PIN → RED → GREEN → SURFACE → CLEAN loop followed for each criterion.
- All QA resources torn down, cleanup receipts recorded.
- If HEAVY tier: reviewer approval obtained before completion.
