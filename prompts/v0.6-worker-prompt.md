# LazyTrae v0.6 — Worker Delegation Prompt
> Extracted from plan/v0.6-cli-installer.md

LazyTrae v0.6 — Implement the LazyTrae CLI.

Implement:
- npx lazytrae-ai init
- npx lazytrae-ai doctor
- npx lazytrae-ai sync
- npx lazytrae-ai uninstall
- npx lazytrae-ai verify
- npx lazytrae-ai handoff

Required behavior:
init:
- detect repo root
- install .trae rules, commands, skills, agents, hooks, MCP
- create .lazytrae state/evidence/log dirs
- create .omo compatibility dirs
- merge AGENTS.md with managed blocks
- never overwrite user content outside managed blocks

doctor:
- validate rules
- validate skills
- validate commands
- validate agents
- validate schemas
- validate .omo mirror
- validate MCP config
- validate hook executability
- validate parity ledger coverage

sync:
- update managed templates
- preserve user edits
- migrate schema versions

uninstall:
- remove managed blocks/files
- preserve evidence/plans by default
- support purge mode

Verification:
- Run init twice and confirm idempotency.
- Run doctor.
- Run sync.
- Run uninstall in a fixture or temp project.
- Record exact outputs.
